# Gielinor – Mobile Prototype

Ein eigenständiger, RuneScape-2008-inspirierter 3D-Einzelspieler-Prototyp für iPhone Safari.

## Start
- `index.html` auf einem Webserver hosten (z. B. GitHub Pages).
- Die Seite auf dem iPhone in Safari öffnen.
- Optional: Safari → Teilen → „Zum Home-Bildschirm“.

Die Three.js-Bibliothek wird beim Laden über jsDelivr eingebunden; zum Spielen ist daher eine Internetverbindung nötig.

## Steuerung
- Auf den Boden tippen: Figur läuft zum Ziel.
- Linker Touch-Joystick: freie Bewegung.
- NPCs/Bäume antippen: Interaktion.
- Inventar / Fertigkeiten / Menü: unten rechts.

## Hinweis
Dies ist ein früher, eigenständiger Prototyp mit Platzhaltermodellen und eigener Grafik. Er enthält keine Original-Assets, keinen Jagex-Login und keine Verbindung zu offiziellen RuneScape-Servern.
